# 요청 체크리스트

대화에서 요청한 내용을 모두 모아 진행 상태를 표시해요. 새 요청이 생기면 계속 추가할게요.

- `[x]` 완료
- `[~]` 일부 완료 (남은 부분은 설명에 적음)
- `[ ]` 아직 안 함

## 진행 방식

- [x] **나중에 컴퓨터의 Claude Code로 이어서 작업할 수 있게 하기**
  모든 작업을 GitHub `dnql8282-glitch/engtest`의 `main` 브랜치에 올렸어요. `git clone`으로 받거나 `claude --teleport`로 이 세션을 이어받으면 돼요.
- [x] **공부용 카피코딩**
  파일마다 한국어 주석을 달았어요.
- [x] **서버 없이 만들기**
  백엔드 없이 동작해요. 사용자 데이터는 브라우저 localStorage에 저장돼요. 다만 영상, 썸네일, 글꼴은 공개 인터넷 주소에서 불러와요.
- [x] **실제 YouTube와 같은 언어**
  youtube.com과 같은 TypeScript로 만들고, React를 함께 썼어요.
- [x] **다른 앱으로 옮기기 좋은 구조**
  `core/` 폴더는 React 없는 순수 TypeScript예요. 저장소도 약속(인터페이스)으로 분리해서, 플랫폼마다 구현만 끼워 넣으면 돼요.
- [x] **실제 개발 템포대로 단계별 진행**
  1단계 → 1.5단계 → 2~5단계를 단계마다 커밋했어요.
- [x] **단계는 알아서 넘어가기**
- [x] **아키텍처 단위로 이해할 수 있게 설명**
  `docs/STAGES.md`에 단계별 개념과 최종 구조도를 정리했어요.
- [x] **보존할 가치가 있는 것만 GitHub에 올리기**
  `node_modules`, `dist`, 큰 스크린샷은 뺐어요.
- [x] **요청 체크리스트 만들기** (이 문서)
- [x] **웹을 먼저 완벽하게 다듬고 앱 개발로 넘어가기** → 아래 "웹 완성도 다듬기" 순서대로 진행 중
